Picpac 当前还是示例包名。 Android 为 com.example.picpac_fe，iOS 为 com.example.picpacFe。如果还没上架，可以先定一个正式标识，两端可以相同。比如持有 yourbrand.cn 时可考虑 cn.yourbrand.picpac；提交时填实际构建使用的值。

Android：改 applicationId，换正式签名

在 Flutter 项目的 android/app/build.gradle.kts 中修改 defaultConfig.applicationId。备案以它为准；如果也改 namespace，同步更新 MainActivity 的包声明及路径。当前 Release 还引用调试签名，先配置正式 Release 签名，再用 flutter build apk --release 出一个包，核对包名并提取签名证书公钥和 MD5。若商店会重新签名，同时确认实际分发证书与填报要求。

Flutter Android 发布指南 ↗

iOS：注册 Bundle ID，配置发布证书

在 Apple Developer 的 Certificates, Identifiers & Profiles → Identifiers 注册显式 App ID。在 macOS 上用 Xcode 打开 ios/Runner.xcworkspace，选 Runner → Signing & Capabilities，设置 Team 和 Bundle Identifier，确保与 App Store Connect 的 App 记录一致。用对应发布证书取公钥和 SHA-1；腾讯云字段即使写着「签名 MD5 值」，iOS 也按其指引填 SHA-1。

03 / SDK INVENTORY

Picpac 实际用了哪些 SDK

腾讯云分类与厂商表 ↗

手机 App：Flutter 和本地功能插件

复核目前的 Android、iOS 客户端锁文件，未发现广告、统计、推送、地图、第三方登录或支付 SDK。已确认的主要运行依赖：

  • Flutter：跨平台应用框架。
  • image_picker 1.2.2：选图；双端分别使用 image_picker_android 和 image_picker_ios。
  • shared_preferences 2.5.5：本地键值存储；双端分别使用 shared_preferences_android 和 shared_preferences_foundation。
  • flutter_svg 2.3.0、cupertino_icons 1.0.9：显示 SVG 和图标。
客户端依赖来源 ↗

Go 后端：阿里云相关服务

阿里云短信验证码（PNVS）、对象存储（OSS），以及通过 HTTP 调用的通义千问（DashScope）图像服务，均确认在后端代码中使用。它们不应因为出现在后端，就填成手机端集成的 SDK。隐私政策仍应按实际启用的服务说明涉及的数据处理。

后端代码来源 ↗
控制台怎么填： 如果 Picpac 没有把 SDK 提供给其他开发者集成，「对外提供 SDK」选否。「使用外部 SDK」以正式发布包和控制台的功能／厂商列表为准：核对 Flutter 是否有对应的框架类条目；通用本地插件不用逐项照抄。若正式包没有接入可匹配的外部 SDK，可按腾讯云指引选「不使用外部 SDK」。上架时另核对隐私政策和商店的披露要求。
04 / STEP BY STEP

腾讯云备案，按这 6 步走

官方首次备案指引 ↗
01

进入控制台，选择 APP 备案

你来操作

登录持有服务器的同一个腾讯云账号，进入 ICP 备案控制台，选择 APP。此前从未备案走首次备案；已有主体则按系统识别的类型办理。

进入腾讯云备案控制台 ↗
02

填个人主体、域名和双端 App 信息

资料填写

主体性质选个人，按要求填身份、地址、联系方式，选择账号内合格服务器。在同一份 APP 备案里填写正式名称，选择 Android 和 iOS，分别填各端实际使用的域名、包名或 Bundle ID、证书公钥和指纹。按清单核对 SDK。

03

上传材料，完成本人身份核验

本人完成

按页面要求上传身份证等材料，通过手机扫码完成视频或人脸核验。核对信息后提交；需要补充的材料以页面和所在省份要求为准。

04

腾讯云初审，及时处理补件

通常 1–2 个工作日

腾讯云审核资料，发现问题会退回修改。保持手机可联系，留意控制台和通知；通过后由腾讯云提交至通信管理局。

05

收到工信部短信，完成核验

24 小时内

收到短信不等于核验完成。 收到验证码后，在有效期内进入工信部备案系统，按要求填验证码和相关身份信息；超时可能被退回。

打开工信部备案管理系统 ↗
06

等待管局审核，获取 APP 备案号

不超过 20 个工作日

管局审核通过后，通过短信、邮件及腾讯云控制台查看结果。20 个工作日是管局审核时限，不包含买域名、实名同步、准备资料、补件和初审的时间。

时间与审核流程依据 腾讯云备案流程 ↗；短信操作依据 工信部短信核验说明 ↗。具体以当前控制台与所在省管局要求为准。
05 / READY TO LAUNCH

备案通过后，怎么上线和改版

A

在 App 内展示备案号

放在“设置”或“关于”等显著位置，并可点击跳转工信部备案系统。应用商店填写对应 APP 备案信息。

查看展示要求 ↗
↗

接通正式 HTTPS 接口，再提交商店

配置 api 子域名解析、SSL 证书和服务器 HTTPS 入口，更新 Flutter 正式接口地址。验证登录、上传等功能后，完成应用商店审核。

域名解析说明 ↗
备案之后可以继续改代码。 修 Bug、改界面、调整后端实现或增加版本号，只要备案信息和已申报的服务内容没有改变，通常无需重复备案。改安装后显示的名称、已备案域名、包名／Bundle ID、证书公钥或指纹，或增加运行平台，先按腾讯云指引核对并办理变更。新增外部 SDK 或改变服务内容时，也要核对备案字段、隐私政策和商店要求。腾讯云变更服务指引 ↗
备案通过 ≠ 应用商店审核通过。 隐私政策、权限说明、账号注销等上架材料和功能，仍需按目标商店及实际业务要求准备。上架后也不要随意更换包名／Bundle ID；商店通常会把不同标识视为另一个 App。
